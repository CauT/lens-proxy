# Contributing

Reproducible bugs, better setup instructions and focused PRs are welcome.
Start with the [development guide](docs/guide/development.md).

- Explain user actions, expected/actual results, version and client platform.
- Discuss substantial features first. Use Conventional Commit subjects.
- Review and redact screenshots and traffic. Never commit keys, credentials,
  captures, SDKs, binaries or private runtime state.
- Preserve captured bytes, explicit errors, cleanup ownership and existing routes.
  Never weaken TLS verification to obtain a pass.
- Run affected checks and state unavailable device/UI coverage. Test the normal
  packaged app and visible Request/Response for UI changes.
- AI-assisted contributions are welcome; the human contributor owns review and
  verification claims. Retain third-party license notices.

Contributions use the repository's MIT license.
